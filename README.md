# Stronux for Claude

A plugin for Claude Code and Claude Desktop that helps you set up courses, guides, services and bundles in your Stronux academy from the files you already have.

Work in progress: the plugin itself arrives in a pull request.

## Install (Claude Code)

```
/plugin marketplace add stronux-ai/stronux-claude
/plugin install stronux@stronux
```
